## v0.6.1 是什么

第一个带 **npm 包 / MCP 工具通道**的发布：把仓库里三个纯标准库 Python 脚本（G1 核验器、`.ioc` 备份还原、`.ioc` 键读写）用一层薄的 Node stdio server 包起来，使任何 MCP 客户端可 `npx cubeone-mcp` 直接拉起。

### 内容

- **新增 MCP 工具通道**（`bin/cubeone-mcp.mjs` + `lib/server.mjs`，3 个工具）：`verify_generation` / `ioc_backup` / `ioc_field`。封装层只做协议、参数透传、路径白名单、写策略门禁与退出码映射，**判据全部留在 Python 脚本里**（单写者边界）。
- **发布流水线**：`.github/workflows/publish.yml` 首次启用 **npm Trusted Publisher（OIDC）**，全程不使用任何长寿 token。
- **文档**：`docs/guides/npm-publish-and-codebuddy.md`（发布与注册全记录）、`SKILL.md` 对齐 0.6.1（新增双通道说明）。
- **仓库更名**：`platform32-mcp` → `cubeone-mcp`，主分支 `main` → `master`（D32）；`docs/logs`、`docs/reports` 里的旧名机械改写 67 个文件 / 446 处，避免证据退化成化石。
